# Collaboration & Contribution Guide: The Quest for AI (TQFAI)

Welcome to the project! Whether you're working on the narrative scene engines, MeTTa hypergraphs, or UI mechanics, this guide outlines how we build together.

## 1. Core Principles & Philosophy
- **Relational Co-Evolution:** We build systems that foster empathy, mutual respect, and emotional regulation (drawing from *The Agency of Mushrooms* framework).
- **Biocentric Governance:** Code and narrative choices prioritize long-term prosocial alignment over extractive or high-entropy patterns.

## 2. Roles & Responsibilities
- **Colleen (Project Lead / Visionary):** Directs narrative arcs, core themes, and overall project scope.
- **Jason Parser (Collaborator):** Focuses on technical implementation, repository architecture, and code integration.
- **Quest (GitHub Copilot Agent):** Assists with automated documentation, code refactoring, and roadmap syncing.

## 3. Workflow & Git Etiquette
1. **Branching:** Create feature branches off `main` (e.g., `feature/metta-integration` or `narrative/chapter-1-updates`).
2. **Pull Requests:** Open a PR for review before merging into `main`. Ensure Copilot instructions and documentation are updated if new architecture or scene mechanics are introduced.
3. **Commit Messages:** Keep them clear and descriptive (e.g., *“Add AI partner archetype selection logic to Scene 1”*).

## 4. Key References
- **Ideation & Pitch:** Rooted in our original R&D Guild proposal (featuring customizable AI partner archetypes: Protector, Bookworm, Scientifically Attuned, Class Clown, and the Wise Owl mascot).
- **Technical Stack:** MeTTa AtomSpace, Probabilistic Logic Networks (PLN), and Omega Hive persistent memory.
